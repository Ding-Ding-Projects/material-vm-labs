Fresh lab machines for build and installer testing

Prove it works on a machine that has never seen your code.

Material VM Labs creates throwaway Windows 11, Ubuntu and Debian lab machines on VMware Workstation, with VirtualBox as the fallback. Each one is installed unattended from official media and kept as a clean baseline snapshot, ready for a fresh-host build, an installer test, Remote Desktop, SSH or a self-hosted runner.

    Quick start

    On a Windows PC with VMware Workstation or VirtualBox, from the repository folder:

    mvl.bat install-cli
mvl hv
mvl media
mvl up proof-1 --project my-project
mvl rdp proof-1
mvl build proof-1 --repo owner/name --entry build,build-installer --evidence evidence\receipts
mvl rm proof-1 --yes

    State lives in %LOCALAPPDATA%\MaterialVmLabs; set MVL_HOME or pass --home to move it. A fresh Windows checkout builds with build.bat, or build.bat /s for a silent run.
