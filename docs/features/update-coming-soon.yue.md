# 即將更新

當有個較新嘅版本整緊嗰陣，Updates（更新）工具會將佢顯示做 **Update coming soon**（即將更新），連埋真實嘅進度。

狀態：**進行中**。

## 佢做啲咩

Manager 會讀 release workflow 喺 GitHub Actions 嘅公開紀錄。如果有一個為比你更新嘅 commit 而行嘅 run 進行緊，佢會顯示建置編號、每個階段（收到 source、排緊隊、每個 workflow 步驟、更新 feed 已經轉咗）同佢嘅狀態、用 24 小時制顯示開始時間同已經用咗幾耐，再加一個由近期成功建置嘅中位數計出嚟嘅剩餘時間估算，清楚標明係估算。佢會列出個建置會包含嘅 commit。個建置發佈咗之後，呢個區塊就會變返做普通嘅更新提供。

## 誠實嘅狀態

建置卡住咗會直講，建置失敗會講明唔會提供，有較新嘅建置取代咗佢都會講，而離線或者俾人限速嘅時候就會將進度顯示做未知，連埋原因。冇建置進行緊嘅時候，個區塊唔會出現。

## 安全同限制

佢永遠唔會下載、安裝或者重新啟動任何嘢。佢唔會傳送任何 token 或者帳戶資料，有建置行緊嗰陣每 3 分鐘查一次，其他時間每 30 分鐘查一次，仲會用 conditional request，確保唔超過 GitHub 嘅匿名限制。

## 狀態同仲有咩未做

已經整好兼有測試覆蓋，等緊同自動更新一樣嘅啟動接駁。仲未對住一個真正進行緊嘅建置觀察過。
