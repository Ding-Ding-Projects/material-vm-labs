# Roadmap, design files and the HTTP API note

The project keeps its status, its designs and its interfaces in the repository where anyone can read them.

Status: **Shipped**.

## What it does

`ROADMAP.md` is a checklist that mirrors the statuses on the features page. The Material 3 design
boards live in `design/canvases/`. Material VM Labs has no HTTP API, so there is no Postman
collection.

## How it was checked

The roadmap and the features index are updated in the same change as the behaviour.
