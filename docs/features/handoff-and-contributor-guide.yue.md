# 貢獻者指南同交接筆記

`AGENTS.md` 話俾任何改呢個 repository 嘅人知啲嘢放喺邊、要跟邊啲規則；`HANDOFF.md` 就記低改咗啲咩、點樣檢查過，同埋仲有咩未做。

狀態：**已推出**。

## 佢做啲咩

`AGENTS.md` 列出目錄結構、建置同測試指令、令個項目保持誠實嘅規則、一份經過清理嘅維護者共用工程指示鏡像，同埋關於對話用詞嘅標準說明。`HANDOFF.md` 淨係講事實：改咗啲咩、證據、剩低嘅工作，同埋任何俾 repository 以外嘅嘢卡住嘅事。`CLOSEOUT_PROMPT.md` 有一段可以直接貼上嘅提示，俾下一個人或者 agent 用嚟完成未做完嘅工作。

## 點樣檢查過

交接筆記係對住而家嘅檔案樹寫嘅；冇證據支持嘅說法會列做未驗證。
