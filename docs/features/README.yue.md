## 實驗機

### 一個指令開一部實驗機

`mvl up` 會開一部 Windows 11、Ubuntu 24.04 或者 Debian 13 機，用官方評估版安裝媒體無人值守咁安裝，裝好客機工具，再影一個乾淨嘅基線快照。再行一次就會將部機還原返嗰個基線再開機。Windows Server 2025 仲係預覽階段：`mvl server-media` 會檢查佢嘅媒體，但係暫時未提供開 Server 機。

狀態：**已推出**。[完整文章](lab-machines.md)。

### 揀 Hypervisor：VMware Workstation 優先，VirtualBox 後備

每次執行，用得到 VMware Workstation 就揀佢，唔得就退返去 VirtualBox，而 `mvl hv` 會話你知會用邊個同點解。

狀態：**已推出**。[完整文章](hypervisor-choice.md)。

### 官方安裝媒體下載同驗證

`mvl media` 會下載官方評估版映像，喺任何機用之前先檢查佢嘅 hash。

狀態：**已推出**。[完整文章](media-verification.md)。

### 全新主機建置收據

`mvl build` 會喺一部乾淨嘅機入面，用一個指定 commit clone 一個 repository，用 `/s` 行佢嘅 `build.bat` 同 `build-installer.bat`，再寫一張收據，入面有 log、產出，同埋建置需要下載嘅每一個相依套件，全部綁定嗰個 commit。

狀態：**已推出**。[完整文章](fresh-build-receipts.md)。

### 安裝程式測試

`mvl install` 會將部機還原返乾淨嘅基線，喺已登入嘅客機 session 入面行你嘅安裝程式，再記低一張連埋客機截圖嘅安裝程式收據。

狀態：**已推出**。[完整文章](installer-tests.md)。

### 私人 repository 用嘅自架 runner

一部實驗機可以幫一個私人 repository 養一個自架 GitHub Actions runner。登記 token 經標準輸入傳入，永遠唔會儲存；如果讀唔到 repository 嘅可見度，就會拒絕開 runner。

狀態：**已推出**。[完整文章](self-hosted-runners.md)。

### Remote Desktop、SSH、共用資料夾同網絡模式

Remote Desktop 一打開就已經登入好，Linux 機用得 SSH，可以共用主機上面嘅資料夾，而每部機都可以用 NAT、bridged 或者 host-only 網絡行；如果 bridged 地址一直都冇嚟，就會自動退返去 NAT。

狀態：**已推出**。[完整文章](remote-access-and-networking.md)。

### 命令列同鍵盤 TUI

`mvl` 會印出簡短嘅文字行（或者 `--json`）俾 script 同 agent 用，而 `mvl tui` 就係俾人用嘅鍵盤管理介面。

狀態：**已推出**。[完整文章](cli-and-tui.md)。

### 客機 Setup app

喺 Windows 實驗機入面，Setup app 會分六步帶擁有者搞掂工具、登入、共用資料夾同最後檢查，有 Back（返轉頭）、Skip（跳過），重新啟動之後仲可以繼續。安裝係喺排程工作入面行，永遠唔會喺 app 入面行，而且永遠唔會讀任何密碼或者 token。

狀態：**已推出**。[完整文章](guest-setup-app.md)。

### 虛擬磁碟管理

喺 Windows 上面建立、掛接、調整大細、壓縮、轉換同合併 VHD、VHDX 同 VHD Set 檔，仲有一個快速打包功能，將拖入嚟嘅檔案變成一個驗證過嘅 VHDX。

狀態：**計劃中**。

### 檔案轉換器

一個本地轉換器，處理文件、PDF、圖片、音訊、影片、壓縮檔同資料，淨係用隨附嘅工具。

狀態：**計劃中**。

### Base64 工具

用每一種 Base64 變體編碼同解碼文字同檔案，有串流、hash 檢查同安全預覽。

狀態：**計劃中**。

### quicktype studio

由 JSON、JSON Schema、TypeScript 同 GraphQL 產生有類型嘅 model，再加一個完整嘅 JSON 編輯器。

狀態：**計劃中**。

### Ollama 管理

一個有引導嘅本地 Ollama 安裝程式同模型管理工具，經 Ollama 嘅本地 API 運作。

狀態：**計劃中**。

### Minecraft 伺服器管理同世界生成器

喺本地、Docker 入面或者經 SSH 建立同管理 Java 同 Bedrock 伺服器，仲可以預先生成世界。

狀態：**計劃中**。

### 喺截圖上面畫嘢

喺截圖、預覽或者一塊空白板上面畫嘢，有七枝筆、一個擦膠、復原，同 SVG 或 PNG 匯出。

狀態：**計劃中**。

### 擴充功能

一個有版本嘅擴充功能格式，有聲明咗嘅權限、同意、時間同大細限制、一個搜尋得嘅管理器、內置擴充功能同一份作者指南。

狀態：**計劃中**。

### 狀態頁

一個狀態目的地，顯示個項目嘅建置同 release 健康狀況，連埋每個狀態背後嘅證據。

狀態：**計劃中**。

## 建置、安裝同更新

### 建置入口

`build.bat` 同 `build-installer.bat` 由一份 Windows checkout 一路整到出啲 app 同安裝程式，用 `/s`、`--silent` 或者 `SILENT=1` 可以靜默咁行，而且會將真正嘅 exit code 照樣傳返出嚟。

狀態：**已推出**。[完整文章](build-entry-points.md)。

### 一個指令全新建置兼執行

喺一個完全全新嘅 Windows 上面行 `.\build.bat --run`，會由鎖定咗嘅來源攞齊每個相依套件、建置、對住已 commit 嘅 source 檢查產出，然後開個 app。啟動前嘅檢查已經整好；`build.bat` 仲要讀到 `--run` 旗標先得。

狀態：**進行中**。[完整文章](fresh-build-and-run.md)。

### 相依套件下載器

`download-dependencies.bat` 同 `download-dependencies.sh` 會將鎖定咗嘅相依套件下載去一個每個用戶獨立嘅資料夾，逐個對 SHA-256 digest，兩個建置 script 都會叫佢。Git 同 .NET SDK 喺記錄到佢哋嘅 digest 之前，淨係會偵測。

狀態：**進行中**。[完整文章](dependency-fetcher.md)。

### Squirrel 安裝程式，冇簽署

啲 app 用 Squirrel.Windows 安裝（`Setup.exe`、`RELEASES` 同完整套件）。乜都冇 code signing，release notes 亦都會講明。

狀態：**已推出**。[完整文章](squirrel-installer.md)。

### 所有嘢都隨附

啲 app 自己帶齊需要嘅嘢，冇網都用得。Hypervisor 係外部產品，亦會清楚講明係外部產品。

狀態：**進行中**。

### App 圖示

每個 app 同安裝程式都有一個真正嘅圖示，全部由同一個來源檔產生。

狀態：**進行中**。
