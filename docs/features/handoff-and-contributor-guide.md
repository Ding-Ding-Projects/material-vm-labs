# Contributor guide and handoff notes

`AGENTS.md` tells anyone changing the repository where things live and which rules apply; `HANDOFF.md` records what changed, how it was checked and what is left.

Status: **Shipped**.

## What it does

`AGENTS.md` lists the layout, the build and test commands, the rules that keep the project honest, a
sanitized mirror of the maintainer's shared engineering instructions and the standard note on
conversation vocabulary. `HANDOFF.md` is factual: what changed, the evidence, the remaining work and
anything blocked by something outside the repository. `CLOSEOUT_PROMPT.md` holds a ready-to-paste
prompt for the next person or agent to finish the open work.

## How it was checked

The handoff is written against the current tree; claims it cannot back with evidence are listed as not verified.
